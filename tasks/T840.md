## Spécification (décidée, ne pas réinterpréter)
`pub fn to_cps2_inputs(j: &JammaInputs, input: &str) -> Cps2Inputs` (entrées JAMMA actives hautes -> ports actifs bas, `active_low`) :
- Octet joueur (dispositions 4 joueurs) : bit 0 droite, 1 gauche, 2 bas, 3 haut, 4 B1, 5 B2, 6 B3, 7 B4. IN0 = J1 | J2 << 8, IN1 = J3 | J4 << 8.
- IN2 : bit 0 = 1 (DO de l'EEPROM, remplacé par l'hôte), bit 1 = test, bit 2 = service, bits 3-7 = 1, bits 8-11 = start J1-J4, bits 12-15 = pièce 1-4.
- `input` ∈ {cps2_2p6b, cps2_2p6bt, cybots} : IN0 bits 7 et 15 à 1 ; IN1 = 0xFFFF sauf bit 0 B4 J1, bit 1 B5 J1, bit 2 B6 J1, bit 4 B4 J2, bit 5 B5 J2 ; IN2 bit 14 = B6 J2 (la pièce 3 n'est pas lue).
- `input == "qndream"` : IN0 bits 0-3 = B4, B3, B2, B1 du J1, bits 8-11 = B4, B3, B2, B1 du J2, autres bits à 1 ; IN1 = 0xFFFF.
- Toute autre disposition CPS2 : règle 4 joueurs.
