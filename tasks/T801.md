## Spécification (décidée, ne pas réinterpréter)
`cps2crypt_tables.rs` est généré par `python tools/gen_cps2crypt_tables.py` (struct `SBox { table: [u8; 64], inputs: [i8; 6], outputs: [u8; 2] }`, `FN1_GROUP_A/B`, `FN2_GROUP_A/B: [u8; 8]`, `FN1_R1_BOXES` … `FN2_R4_BOXES: [SBox; 4]`). `lib.rs` : `#[rustfmt::skip] pub mod cps2crypt_tables;` et `pub mod cps2crypt;`.
Port 1:1 dans `cps2crypt.rs`, dans l'ordre du fichier :
- `struct OptimisedSbox { input_lookup: [u8; 256], output: [u8; 64] }` : `optimise(&SBox)` (extract_inputs : pour i de 0 à 5, si `inputs[i] >= 0`, `res |= bit(val, inputs[i]) << i` ; sorties : bit 0 de `table[i]` -> `1 << outputs[0]`, bit 1 -> `1 << outputs[1]`) ; `apply(input: u8, key: u32) -> u8` = `output[input_lookup[input] ^ (key & 0x3F)]` (PORT-NOTE : `fn` est un mot réservé).
- `sbox_fn(input, sboxes: &[OptimisedSbox], key)` = OU des 4 boîtes avec `key`, `key >> 6`, `key >> 12`, `key >> 18` (MAME `fn`, PORT-NOTE).
- `expand_1st_key(src: &[u32; 2]) -> [u32; 4]`, `expand_2nd_key(src) -> [u32; 4]`, `expand_subkey(seed: u16) -> [u32; 2]` : tables `bits` recopiées telles quelles ; `dst[i / 24] |= bit(src[bits[i] / 32], bits[i] % 32) << (i % 24)`.
- `feistel(val: u16, bits_a: &[u8; 8], bits_b: &[u8; 8], boxes: [&[OptimisedSbox]; 4], key: [u32; 4]) -> u16` : `bitswap<8>(val, B7, …, B0)` = octet dont le bit k vaut `bit(val, bitsB[k])` (idem `r` avec bitsA) ; 4 demi-tours ; recomposition l.606-621.
- `pub fn cps2_decrypt(rom: &[u16], master_key: [u32; 2], lower_limit: u32, upper_limit: u32) -> Vec<u16>` : `length / 2 = rom.len()` ; bits supplémentaires de key1 (l.655-661) et key2 (l.689-696) ; boucle l.663-712 ; bornes **incluses**.
- `pub struct Cps2Key { pub master: [u32; 2], pub lower: u32, pub upper: u32 }` et `pub fn decode_key(key: &[u8]) -> Cps2Key` (init_cps2crypt l.10959-10986, `key.len() >= 20`).
- `pub fn decrypt_program(rom: &[u8], key: &Cps2Key) -> Vec<u8>` : mots gros-boutistes (octet fort d'abord), `cps2_decrypt(mots, key.master, key.lower / 2, key.upper / 2)`, résultat en octets gros-boutistes.

## Règles de portage C++ -> Rust (cartes « port »)
- Traduire fonction par fonction, DANS L'ORDRE du fichier source, mêmes noms en snake_case (`cps1_build_palette` -> `cps1_build_palette` ou nom indiqué). Ne pas « optimiser », ne pas fusionner, ne pas réordonner.
- Types : `int` -> i32, `uint8_t/uint16_t/uint32_t` -> u8/u16/u32 ; arithmétique non signée modulo 2^N : `wrapping_*` ou masques explicites ; division entière C++ = division Rust sur i32 (troncature vers 0).
- Conserver l'en-tête de licence (`// license:BSD-3-Clause` + `// copyright-holders:` du fichier source) en tête de chaque fichier Rust porté, avec le nom du fichier source et les lignes portées.
- Construction sans équivalent évident : écrire la plus simple équivalente et noter `// PORT-NOTE:` ; ne jamais changer le comportement.
