## Spécification (décidée, ne pas réinterpréter)
`resample.rs` : rééchantillonneur linéaire mono/stéréo de `cps_core::AUDIO_HZ` vers la fréquence du périphérique (repris de `AudioResampler` de audio_mix.rs). `audio.rs` : flux cpal (périphérique par défaut, f32), tampon SPSC (crossbeam `ArrayQueue` ou anneau à base de Mutex<VecDeque> : seules les dépendances autorisées), remplissage par le thread d'émulation avec `take_audio()`. Dérive (Q-AUDIOCLK) : si le tampon dépasse 3 trames de son, ajuster la fréquence source de ±0,5 % (comme Neo Geo) ; s'il est vide, sortir du silence. Pas de son si aucun périphérique (message dans la barre d'état).
