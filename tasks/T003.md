## Spécification (décidée, ne pas réinterpréter)
Les dépendances sont DÉJÀ déclarées dans `Cargo.toml` (`[workspace.dependencies]`, révisions épinglées identiques à Puce16 Neo Geo) et utilisées par `cps-core` (puce-m68k, puce-z80) et `cps-bus` (puce-z80). Cette carte : (1) `cargo fetch` puis `cargo build -p cps-core` doivent réussir ; (2) écrire le test de fumée qui fixe le contrat d'utilisation des deux crates (ne JAMAIS les modifier : un manque se note dans `docs/QUESTIONS.md`).
API utilisée par tout le projet (voir `ref/cpu-crates/`) :
- 68000 : `use puce_m68k::{bus::Bus, cpu::Cpu, pins::Pins};` `Bus::{read(addr:u32,fc:u8,uds:bool,lds:bool)->u16, write(addr,fc,uds,lds,data:u16), wait_clocks(addr,write)->u8, ipl()->u8, int_ack(level)->Option<u8>, on_tick(Pins)}` ; `Cpu::{new, reset, step(&mut bus)->u32, step_clock(&mut bus)->Option<bool>, state()->CpuState, load_state, at_instruction_boundary, is_stopped, is_halted}`. `reset()` démarre la séquence de reset (40 horloges) qui se termine pendant les `step_clock` suivants. Une horloge = un appel de `on_tick`. `Bus::read` est appelé à l'horloge 3 d'un cycle de bus, `Bus::write` à l'horloge 2 ; `wait_clocks` à l'horloge 0.
- Z80 : `use puce_z80::{Cpu, Pins};` `Cpu::{new, reset, tick(Pins)->Pins, at_instruction_boundary, step(&mut Bus)->u32}` ; champ public `cpu.regs`. Un `tick` = un T-state. Le projet utilise l'API broches (`tick`, T103).
Test de fumée (valeurs mesurées sur ces révisions, identiques à Puce16 Neo Geo T005) :
1. 68000 : RAM 64 Kio miroir, vecteurs SSP=0x1000 (octets 00 00 10 00), PC=0x100 (00 00 01 00) ; à 0x100 : `30 3C 12 34` (MOVE.W #$1234,D0) `4E 72 27 00` (STOP #$2700). Boucle `step_clock` avec un compteur `ticks` incrémenté dans `on_tick` : première frontière d'instruction après **40** ticks (`state().pc == 0x104`, `state().ssp == 0x1000`), la suivante après **48** ticks (`state().d[0] == 0x1234`), puis `is_stopped()` et une frontière tous les 4 ticks.
2. 68000, attente : `MOVE.W $200,D1` (`32 39 00 00 02 00`) dure 16 ticks sans attente et 18 si `wait_clocks(0x200,false)` renvoie 2.
3. Z80 (API `step`) : `3E 01 87 76` (LD A,1 ; ADD A,A ; HALT) : 3 appels de `step` => `regs.a == 2` et 15 T-states au total.
