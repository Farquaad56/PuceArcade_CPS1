## Spécification (décidée, ne pas réinterpréter)
1. `ym2151.rs` : port 1:1 de la classe `ym2151` (variante YM2151 seulement) : `new(intf)`, `reset`, `read_status` (statut | 0x80 si busy), `read(offset)` (offset & 1 == 1 -> statut, sinon 0xFF), `write_address`, `write_data` (l.482-498 : écriture moteur, `external_write` pour 0x1B ignoré côté CPS1, puis `set_busy_end(32 * prescale)` = 64 horloges), `write(offset, data)`, `generate(&mut Output<2>)` (clock(ALL) ; output(0, 32767, ALL) ; roundtrip_fp).
2. `clocked.rs` — adaptateur à la structure de `ym_adapter.rs` de Neo Geo (interface partagée Rc<RefCell<..>> ou équivalent) avec le temps en HORLOGES YM :
```rust
pub struct ClockedYm2151 { /* chip, time: u64 (horloges YM), deadlines: [Option<u64>; 2], busy_end: u64, irq: bool, samples_done: u64, out: Vec<[i32; 2]> */ }
impl ClockedYm2151 {
    pub fn new() -> Self; pub fn reset(&mut self);
    pub fn time(&self) -> u64;
    pub fn advance_to(&mut self, t: u64);       // voir ci-dessous
    pub fn write(&mut self, offset: u8, data: u8);   // à l'instant courant
    pub fn read(&mut self, offset: u8) -> u8;
    pub fn irq(&self) -> bool;
    pub fn next_sample_clock(&self) -> u64;     // (samples_done + 1) * 64
    pub fn take_samples(&mut self) -> Vec<[i32; 2]>;   // échantillons bruts écrêtés à [-32768, 32767]
}
```
`set_timer(n, d)` : deadline = time + d (d < 0 : None) ; `set_busy_end(c)` : busy_end = time + c ; `is_busy` : time < busy_end.
`advance_to(t)` : boucle { ns = next_sample_clock() ; nt = plus petite deadline ; si nt existe et nt <= min(ns, t) : time = nt, deadline = None, `engine_timer_expired(n)` ; sinon si ns <= t : time = ns, generate, push, samples_done += 1 ; sinon fin } ; time = t. (À égalité timer/échantillon : timer d'abord, comme l'oracle.)
