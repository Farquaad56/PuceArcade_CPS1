## Spécification (décidée, ne pas réinterpréter)
1. `Machine::new` : si `game.cps2` est Some (en plus du cas QSound existant, qui s'applique aussi : DSP et opcodes Z80 présents) : `bus.video = cps_gfx::Video::new_cps2(nom)` ; `bus.cps2 = Some(Box::new(Cps2Io::new(dead, singbrd)))` ; `bus.qsound = false` (pas de ports F1C0xx) ; `bus.user1 = None` ; `bus.eeprom = Some(Eeprom93c46::new_16bit())` ; `Machine` gagne `pub opcodes: Option<Vec<u8>>` (= `cps2.opcodes`).
2. `Host68k` gagne `opcodes: Option<&'a [u8]>`. `read` : si `fc & 3 == 2`, adresse < 0x400000 et opcodes présents -> mot gros-boutiste des opcodes ; sinon chemin actuel. Le `_fc` actuel devient `fc`.
3. `host_cps2.rs` (`impl Host68k<'_>`) : `cps2_read(a) -> Option<u16>` et `cps2_write(a, lds, data) -> bool`, appelés dans `read` / `write` quand `bus.cps2` est Some (à la place de `qsound_read` / `qsound_write`) : 618000-619FFF -> `0xFF00 | sound.ram[(a - 0x618000) / 2]` en lecture, écriture de l'octet bas si lds (RAM partagée 1 = Z80 C000-CFFF).
4. `Machine::set_cps2_inputs(&mut self, i: Cps2Inputs)` : copie dans `bus.cps2.inputs`.
