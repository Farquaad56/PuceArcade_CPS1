## Spécification (décidée, ne pas réinterpréter)
Pas de cache de tuiles (MAME en a un, sans effet visible) : chaque pixel est calculé à la demande.
```rust
pub const TILEMAP_DIM: [u32; 3] = [512, 1024, 2048];       // largeur = hauteur
pub fn tilemap0_scan(col: u32, row: u32) -> u32; pub fn tilemap1_scan(col: u32, row: u32) -> u32; pub fn tilemap2_scan(col: u32, row: u32) -> u32;
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub struct TilePixel { pub pen: u16, pub layer0: bool, pub layer1: bool }
impl Video {
    pub fn update_transmasks(&self) -> [u16; 4];                                    // l.2515-2531 : regs_b[prio/2] ^ 0xFFFF, ou 0xFFFF si prio == -1
    pub fn tilemap_pixel(&self, gfx: &[u8], layer: usize, tx: u32, ty: u32, masks: &[u16; 4]) -> TilePixel;   // coordonnées DANS la tilemap
    pub fn tilemap_scroll(&self, layer: usize, sy: u32) -> (i32, i32);              // (scrollx effectif pour la ligne écran sy, scrolly)
}
```
`tilemap_pixel` : tile = (tx / taille, ty / taille) ; index = scanN(col, row) ; `code = gfxram[scroll_base + 2*index]` (couche 2 : `& 0x3FFF`), `attr = gfxram[... + 1]` (index modulo GFXRAM_WORDS) ; code mappé (SCROLL1/2/3) ; layout : couche 0 -> L8x8 si `index & 0x20 == 0` sinon L8x8b ; couche 1 -> L16x16 ; couche 2 -> L32x32 ; px = tx % taille, py = ty % taille ; flipX (attr bit5) -> px = taille-1-px ; flipY (bit6) -> py = taille-1-py ; raw = 15 si code == -1 sinon tile_pixel ; couleur = (attr & 0x1F) + 0x20/0x40/0x60 ; `pen = (couleur % 0x80) * 16 + raw` ; groupe g = (attr & 0x180) >> 7 ; `layer1 = raw != 15` ; `layer0 = (masks[g] >> raw) & 1 == 0`.
`tilemap_scroll` : couche 1 avec VIDEOCONTROL bit0 : `scrollx = bases.scrollx[1] + gfxram[other + ((sy as i32 + regs_a[16] as i32) & 0x3FF)] as i32` (sy < 256) ; sinon bases.scrollx[layer]. scrolly = bases.scrolly[layer].
Pixel affiché en (sx, sy) écran : `tx = (sx as i32 + scrollx).rem_euclid(W)`, `ty = (sy as i32 + scrolly).rem_euclid(W)` (helper `pub fn screen_to_tilemap(...)` à écrire).
