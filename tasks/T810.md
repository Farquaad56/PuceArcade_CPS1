## Spécification (décidée, ne pas réinterpréter)
1. `cps2.rs` : `#[derive(Clone, Debug)]` + serde (voir règles) `pub struct Cps2Video { pub objram1: Vec<u16>, pub objram2: Vec<u16>, pub objram_bank: u16, pub output: [u16; 6], pub buffered_obj: Vec<u16>, pub last_sprite: i32, pub pri_ctrl: u16 }` ; `Default` : RAM objets et tampon de 0x1000 mots à 0, `last_sprite = 0`.
2. Port 1:1 (méthodes de `Cps2Video`) : `objram_bank_w(data, lds)` (`ACCESSING_BITS_0_7` = lds), `objram1_r`, `objram2_r`, `objram1_w`, `objram2_w` (COMBINE_DATA : uds = octet fort, lds = octet faible ; offset en mots modulo 0x1000), `objbase(&self) -> &[u16]`, `output_r(word) -> u16`, `output_w(word, data, uds, lds)` (COMBINE_DATA), `objram_latch(&mut self)` (pri_ctrl = output[2], copie de `objbase()` dans `buffered_obj`), `find_last_sprite(&mut self)` (seulement la partie CPS2 l.877-893 ; la partie CPS1 reste dans le rendu).
3. `regs.rs` : `Video` gagne `pub cps2: Option<Box<Cps2Video>>` (None dans `new`) ; `pub fn new_cps2(game: &str) -> Self` = `new(game)` avec `cps2 = Some(Box::default())`. La configuration d'un nom CPS2 est celle de « cps2 » (`find_config` retombe sur cps2 pour un nom inconnu : à vérifier par un test, ne rien changer à config.rs).

## Règles de portage C++ -> Rust (cartes « port »)
- Traduire fonction par fonction, DANS L'ORDRE du fichier source, mêmes noms en snake_case (`cps1_build_palette` -> `cps1_build_palette` ou nom indiqué). Ne pas « optimiser », ne pas fusionner, ne pas réordonner.
- Types : `int` -> i32, `uint8_t/uint16_t/uint32_t` -> u8/u16/u32 ; arithmétique non signée modulo 2^N : `wrapping_*` ou masques explicites ; division entière C++ = division Rust sur i32 (troncature vers 0).
- Conserver l'en-tête de licence (`// license:BSD-3-Clause` + `// copyright-holders:` du fichier source) en tête de chaque fichier Rust porté, avec le nom du fichier source et les lignes portées.
- Construction sans équivalent évident : écrire la plus simple équivalente et noter `// PORT-NOTE:` ; ne jamais changer le comportement.

## Tests à écrire (valeurs exactes)
- Banque 0 : `objram2_w(3, 0xABCD, true, true)` écrit objram2[3] ; banque 1 (`objram_bank_w(1, true)`) : même appel écrit objram1[3], `objram2_r(3)` lit objram1[3]. `objram_bank_w(1, false)` (octet faible non écrit) ne change pas la banque.
- `objbase` : banque 0 -> objram1, banque 1 -> objram2.
- `output_w(2, 0x1234, true, true)` puis `objram_latch` : `pri_ctrl == 0x1234`, `buffered_obj == objbase()`.
- find_last_sprite : `buffered_obj[9] = 0x8000` -> last = 4 ; `buffered_obj[3] = 0xFF00` -> last = -4 ; aucune marque -> last = 0xFFC.
- `Video::new_cps2("ssf2ud").cfg` est la configuration de « cps2 » (même `layer_control` que `find_config("cps2")`).
