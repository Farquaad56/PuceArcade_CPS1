Séquence exacte (spec 02 §Composition) : flip = regs_a[17] bit15 (en P2 : si flip, `debug_assert!` absent, on suit seulement la position des sprites ; le flip des tilemaps arrive en T605) ; `get_video_base()` ; `self.last_sprite = find_last_sprite(&self.buffered_obj, cfg.bootleg_kludge)` ; `masks = update_transmasks()` ; bitmap 512×262 rempli de 0xBFF ; étoiles : rien en P2 ; pri = 0 ; l0..l3 = (lc >> 6/8/10/12) & 3 ; dessiner(l0) ; si l1 == 0 { haute(l0) } ; dessiner(l1) ; si l2 == 0 { haute(l1) } ; dessiner(l2) ; si l3 == 0 { haute(l2) } ; dessiner(l3). dessiner(0) = render_sprites ; dessiner(n) = draw_tilemap(n-1) ; haute(0) = rien ; haute(n) = draw_tilemap_high(n-1). Une couche non activée (`bases.layer_enabled`) ne dessine rien. Pour chaque ligne visible sy ∈ 16..=239 et sx ∈ 64..=447 : tx/ty via `tilemap_scroll(layer, sy)` + `screen_to_tilemap`. Enfin `fb.pixels[(sy-16)*384 + (sx-64)] = palette[bitmap[sy*512+sx] as usize]`.

## Tests à écrire (valeurs exactes)
- Scène vide (ghouls, regs_b[0x13] = 0, entrée 0 de buffered_obj = marqueur) : palette[0xBFF] = 0x123456 -> tous les pixels du fb valent 0x123456 ; crc32 identique sur deux rendus.
- Priorité (ghouls) : gfx = vec![0xFF; 0x10000] ; tuile scroll1 code 4 (L8x8, octets 256..319) entièrement raw 8 (pour chaque ligne y : octets 256+8y+0..2 = 0x00, +3 = 0xFF) placée en col 8, row 2 (index tilemap0_scan(8,2) = 258 -> gfxram[516] = 4, gfxram[517] = 0x0003) : elle couvre l'écran (64..71, 16..23) ; sprite code 8 (16x16, octets 1024..1151) avec raw 8 en (0,0) (octets 1024..1026 = 0x7F), entrée 0 = [64, 16, 8, 0x0001], entrée 1 = marqueur. lc = regs_b[0x13] = 0x3842 (enable 0x02, l0 = 1 scroll1, l1 = 0 sprites, l2 = 2, l3 = 3). Palette : palette[0x18] = 0xAA0000, palette[0x238] = 0x00BB00. Sans priorité (regs_b[0x14] = 0) : fb(0,0) == 0xAA0000 ; avec regs_b[0x14] = 0x0100 : fb(0,0) == 0x00BB00 ; fb(1,0) == 0x00BB00 dans les deux cas.
- Ordre inverse lc = 0x3902 (l0 = 0 sprites, l1 = 1 scroll1) : fb(0,0) == 0x00BB00 même sans priorité (la tuile est dessinée après le sprite).
- Rowscroll actif : décalage horizontal d'une ligne visible conforme à tilemap_scroll (une tuile 16x16 décalée de 5 pixels sur la seule ligne 20).
