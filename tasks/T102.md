## Spécification (décidée, ne pas réinterpréter)
```rust
// video_port.rs — implémenté pour cps_gfx::Video en T207 ; un stub suffit pour les tests de cette carte
pub trait VideoPort {
    fn cps_a_write(&mut self, word: usize, data: u16, uds: bool, lds: bool);     // word = 0..31
    fn cps_b_read(&mut self, word: usize) -> u16;
    fn cps_b_write(&mut self, word: usize, data: u16, uds: bool, lds: bool);
    fn gfxram_read(&self, word: usize) -> u16;                                  // word = 0..0x17FFF
    fn gfxram_write(&mut self, word: usize, data: u16, uds: bool, lds: bool);
    fn set_inputs(&mut self, in2: u8, in3: u8);
}
// map68k.rs
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum SoundCmd { Latch1(u8), Latch2(u8) }
pub struct Bus68k<V: VideoPort> { pub rom: Vec<u8>, pub ram: Vec<u8>, pub video: V, pub inputs: InputState, pub dips: Dips, pub coinctrl: u16 }
impl<V: VideoPort> Bus68k<V> {
    pub fn new(rom: Vec<u8>, video: V, dips: Dips) -> Self;     // ram = vec![0; 0x10000]
    pub fn reset(&mut self);                                     // ram à 0, coinctrl 0 (la vidéo est remise à zéro par son propriétaire)
    pub fn set_inputs(&mut self, i: InputState);                 // + video.set_inputs(i.in2, i.in3)
    pub fn read16(&mut self, addr: u32, uds: bool, lds: bool) -> u16;
    pub fn write16(&mut self, addr: u32, uds: bool, lds: bool, data: u16) -> Option<SoundCmd>;
}
```
Décodage EXACT de docs/spec/01 §68000 (adresse & 0xFFFFFF, bit 0 ignoré : les accès sont des mots + strobes). ROM et RAM big-endian : mot = (b[a] << 8) | b[a+1] ; écriture RAM : octet haut si uds, bas si lds. ROM : lecture au-delà de `rom.len()` -> 0 ; écriture ignorée. Lecture non mappée 0, écriture non mappée ignorée. GFXRAM 900000-92FFFF -> `video.gfxram_*((a - 0x900000) / 2)` ; CPS-A 800100-80013F -> `video.cps_a_write((a - 0x800100) / 2, ..)` (lecture 0) ; CPS-B 800140-80017F -> `video.cps_b_*((a - 0x800140) / 2)`. coinctrl : `combine_data`. Chaque constante d'adresse : `// spec: docs/spec/01 §68000`.

## Tests à écrire (valeurs exactes)
- ROM [0x12,0x34,0x56,0x78…] : read16(0) == 0x1234, read16(2) == 0x5678 ; read16(0x3FFFFE) avec rom de 4 octets == 0 ; write16 en ROM sans effet.
- RAM : write16(0xFF0000, true, false, 0xAB12) puis read16(0xFF0000, true, true) == 0xAB00 ; write16(0xFF0000, false, true, 0x00CD) -> 0xABCD ; read16(0x1FF0000) == read16(0xFF0000) (masque 24 bits).
- inputs.in1 = 0x7FFE : read16(0x800000) == read16(0x800006) == 0x7FFE ; in0 = 0xEF : read16(0x800018) == 0xEFFF ; dips {0x12,0x34,0x56} : 0x80001A -> 0x12FF, 0x80001C -> 0x34FF, 0x80001E -> 0x56FF ; read16(0x800020) == 0.
- write16(0x800180, true, true, 0x00AB) == Some(Latch1(0xAB)) ; (0x800180, false, true, 0x0042) == Some(Latch1(0x42)) ; (0x800180, true, false, 0x4200) == Some(Latch1(0x42)) ; (0x800188, false, true, 0x0077) == Some(Latch2(0x77)) ; (0x800188, true, false, 0x7700) == None.
- Stub VideoPort enregistrant les appels : write16(0x80010A, ..) -> cps_a_write(5, ..) ; read16(0x800172) -> cps_b_read(0x19) ; read16(0x800100) == 0 sans appel ; write16(0x92FFFE, ..) -> gfxram_write(0x17FFF, ..) ; read16(0x930000) == 0 sans appel.
