## Spécification (décidée, ne pas réinterpréter)
1. `regions.rs` : `Regions` gagne `pub key: Option<Vec<u8>>`, rempli par la région "key".
2. `cps2load.rs` : `pub fn unshuffle(buf: &mut [u8], len: usize)` port 1:1 de l.768-786 sur des **blocs de 8 octets** (un `uint64_t` = 8 octets déplacés ensemble ; `len` en blocs) ; `pub fn cps2_gfx_decode(gfx: &mut [u8])` : pour chaque banque de 0x200000 octets, `unshuffle(banque, 0x200000 / 8)` (une banque incomplète en fin de région est traitée avec sa propre taille en blocs, puissance de deux ou multiple de 4 ; aucune région CPS2 n'en a).
3. `game.rs` : `Game` gagne `pub ticks_68k_den: u64` et `pub cps2: Option<Cps2Rom>` ; `pub struct Cps2Rom { pub opcodes: Vec<u8>, pub dead: bool, pub singbrd: bool }` (dans cps2load.rs, réexportée). `ticks_per_68k` : "cps2" | "dead_cps2" => 25200 ; `pub fn ticks_68k_den(machine: &str) -> u64` : 59 pour ces deux machines, 1 sinon (ADR-007).
4. `load_game_from` : si `system_of(info) == Cps2` : `cps2_gfx_decode(&mut regions.gfx)` ; `key = regions.key` (absente : nouvelle erreur `CartError::MissingKey(String)` avec le nom du jeu) ; `opcodes = decrypt_program(&regions.maincpu, &decode_key(&key))` ; `audio_opcodes = Some(regions.audiocpu[..0x8000].to_vec())` (Z80 en clair, mêmes conventions que le Kabuki du CPS1) ; `qsound_dsp = Some(src.fetch("dl-1425.bin", DL1425_CRC)?)` ; `dead = machine == "dead_cps2"`, `singbrd = init == "init_singbrd"`, `cpsb_at_1c0 = false`. CPS1 : `ticks_68k_den = 1`, `cps2 = None`, rien d'autre ne change.
5. **Exception à « un crate par carte »** (sinon cps-core ne compile plus) : dans `crates/cps-core/src/machine.rs`, `synthetic_game` construit un `cps_cart::Game` littéral : y ajouter seulement `ticks_68k_den: 1,` et `cps2: None,`. Aucune autre modification hors de cps-cart.

## Tests à écrire (valeurs exactes)
- unshuffle sur des blocs dont le premier octet vaut l'indice d'origine : 4 blocs -> ordre [0, 2, 1, 3] ; 8 -> [0, 2, 4, 6, 1, 3, 5, 7] ; 16 -> [0, 2, 4, 6, 8, 10, 12, 14, 1, 3, 5, 7, 9, 11, 13, 15].
- Une banque entière (0x40000 blocs, indice d'origine écrit en u32 gros-boutiste dans les 4 premiers octets) : position 0 -> 0, 1 -> 2, 2 -> 4, 5 -> 0xA, 0x20000 -> 1, 0x3FFFF -> 0x3FFFF, 0x12345 -> 0x2468A.
- `ticks_per_68k("cps2") == 25200`, `ticks_68k_den("cps2") == 59`, `ticks_68k_den("cps1_10MHz") == 1`.
