## Spécification (décidée, ne pas réinterpréter)
ADR-003 étape (b), seulement quand `bus.video.raster` est Some (CPS1 inchangé).
1. `Machine` gagne `pub next_line: Tick` (début de la prochaine ligne ; 0 au reset) et `pub raster_irq_at: Option<Tick>`, passés à `Host68k`.
2. `raster_sched.rs` : `fn raster_events(host)` appelée dans `on_tick` après le rattrapage du Z80 et avant le test du VBLANK : tant que `now >= next_line` : `line = (next_line % TICKS_PER_FRAME) / TICKS_PER_LINE` ; si `raster.raster_scanline(line as u32)` rend `Some(d)` : `raster_irq_at = Some(next_line + d as u64 * TICKS_PER_PIXEL)` ; `next_line += TICKS_PER_LINE`. Puis si `raster_irq_at` est atteint : `*ipl2 = true`, `raster_irq_at = None` (le rendu partiel viendra en T851).
3. Avant chaque `bus.read16` / `bus.write16` (quand raster est Some) : `bus.video.hpos = ((now % TICKS_PER_LINE) / TICKS_PER_PIXEL) as u32`.
4. L'IRQ2 de VBLANK reste celle de `vblank_event` (ligne 240) ; `ipl()` donne déjà 6 quand IPL1 et IPL2 sont actifs ; `int_ack` les efface tous les deux (irqack_r).

## Tests à écrire (valeurs exactes)
Machine synthétique avec `video.raster = Some(Raster::new())` et `reload[0] = 10` (écriture directe) :
- `raster_scanline` est appelé pour les lignes 0, 1, 2… dans l'ordre (compteur 0 rechargé à 10 en ligne 0, atteint 0 en ligne 10).
- `ipl2` passe à vrai au tick où `now >= 10 × 322 560 + reload[2] × 2 × 630` (reload[2] = 0 : début de la ligne 10), pas avant.
- `hpos` vaut `(now % 322 560) / 630` au moment d'une lecture CPS-B.
- Machine synthétique CPS1 (`raster` None) : `ipl2` jamais mis, tests existants verts.
