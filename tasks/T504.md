## Spécification (décidée, ne pas réinterpréter)
Compléter `BoardDebug` :
- registers = groupes "CPS-A" (18 registres nommés comme regs.rs, valeur hex 4 chiffres), "CPS-B" (layer_control brut + ordre décodé « l0 l1 l2 l3 » avec noms Sprites/Scroll1/2/3, enables, 4 masques de priorité, palette_control, id CPS-B de la config), "Sprites" (entrées de `buffered_obj` jusqu'au marqueur, max 64 : « x y code attr -> code mappé »), "Son" (latch1, latch2, banque, broche 7 OKI, voix OKI actives).
- images = "Palette" (64 × 48, pixel i = palette[i]), "Tuiles 16x16" (256 × 256 : codes `page*256 .. page*256+255` en grille 16×16, page 0, pens bruts affichés en niveaux de gris `v * 0x111111`), "Tuiles 8x8" (128 × 128, 256 codes), "Tuiles 32x32" (512 × 512, 256 codes).
- layer_names = ["Sprites", "Scroll 1", "Scroll 2", "Scroll 3", "Étoiles"] ; set_layer_mask(m) -> `machine.bus.video.debug_layer_mask = m` (T206 l'applique au rendu suivant).
