## Spécification (décidée, ne pas réinterpréter)

## Tests à écrire (valeurs exactes)
- Programme : SSP 0x00FF8000, PC 0x400 ; vecteur 26 (0x68) = 0x00000500 ; 0x400 : `46FC 2000` (MOVE #$2000,SR) `60FE` ; 0x500 : `5279 00FF 0000` (ADDQ.W #1,$FF0000) `4E73` (RTE). Après 3 run_frame : mot RAM 0xFF0000 == 3 et ipl1 == false (acquitté).
- Avec `46FC 2700` (IRQ masquées) : après 2 run_frame, mot 0xFF0000 == 0 et `ipl1 == true` (jamais acquitté).
- Trame 1 d'un programme qui ne touche pas la vidéo : palette noire -> tous les pixels du fb == 0 ; programme à 0x400 : `33FC F800 0091 57FE` (MOVE.W #$F800,$9157FE = GFXRAM 0x914000 + 0xBFF*2) `33FC 003F 0080 0170` (CPS-B palette_control) `33FC 9140 0080 010A` (CPS-A PALETTE_BASE, déclenche la copie) `60FE` : fb(0,0) == 0x880000 à la trame suivante.
