## Spécification (décidée, ne pas réinterpréter)
Le rendu travaille sur un bitmap « écran MAME » : `pub const BITMAP_W: usize = 512; pub const BITMAP_H: usize = 262;` (u16 = pen) et un bitmap de priorité u8 de même taille ; rectangle de clip `x 64..=447, y 16..=239` (`pub const CLIP: (usize, usize, usize, usize) = (64, 447, 16, 239)`).
```rust
pub fn find_last_sprite(obj: &[u16], kludge: i32) -> i32;           // l.2684-2718 (branche kludge&15 == 3 comprise)
impl Video {
    pub fn render_sprites(&mut self, gfx: &[u8], bitmap: &mut [u16], pri: &mut [u8], flip: bool);   // l.2720-2866 sur self.buffered_obj et self.last_sprite
}
pub fn prio_transpen16(gfx: &[u8], bitmap: &mut [u16], pri: &mut [u8], code: u32, color: u32, flipx: bool, flipy: bool, sx: i32, sy: i32, pmask: u32);
```
`prio_transpen16` (drawgfx.cpp l.910-938 + drawgfxt.ipp l.216-227) : layout L16x16, `pmask |= 1 << 31`, couleur de base `(color % 0x80) * 16` ; pour chaque pixel (x, y) de 0..16 (source lue en 15-x / 15-y si flip) dont la destination (sx+x, sy+y) est dans CLIP : si `v != 15` : si `(1u32 << (pri & 0x1F)) & pmask == 0` -> bitmap = base + v ; puis `pri = 31` (même si non dessiné). Pas de rebouclage.
Dans CETTE carte : constantes, `find_last_sprite` et `prio_transpen16` seulement ; `render_sprites` est la carte T205b.

- Traduire fonction par fonction, DANS L'ORDRE du fichier source, mêmes noms en snake_case (`cps1_build_palette` -> `cps1_build_palette` ou nom indiqué). Ne pas « optimiser », ne pas fusionner, ne pas réordonner.
