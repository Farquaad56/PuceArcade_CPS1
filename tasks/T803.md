## Spécification (décidée, ne pas réinterpréter)
Le port actuel est figé en 8 bits (constantes ADDRESS_BITS = 7, DATA_BITS = 8, COMMAND_ADDRESS_BITS = 7). Le CPS2 utilise `EEPROM_93C46_16BIT` (eepromser.cpp l.1100 : 64 mots de 16 bits, 6 bits d'adresse).
1. Remplacer les trois constantes par des champs `address_bits: u32` et `data_bits: u32` (sérialisés) ; `command_address_bits = address_bits` (eepromser.cpp l.186-187). `new()` = organisation 8 bits, comportement et tests actuels inchangés.
2. `pub fn new_16bit() -> Self` : address_bits 6, data_bits 16, `data` = 128 octets à 0xFF (valeur par défaut ~0).
3. `internal_read(address)` / `internal_write(address, value)` (eeprom.cpp l.283-303) : en 16 bits, mot **petit-boutiste** `data[2a] | data[2a + 1] << 8` ; en 8 bits, `data[a]`. Toutes les lectures, écritures, effacements et `write_all` passent par elles ; masque d'effacement `(1 << data_bits) - 1`.
4. Registre à décalage : `read(...) << (32 - data_bits)` (eepromser.cpp l.416), fin d'écriture quand `bits_accum == data_bits` (l.442), adresse lue `(address + bits_accum / data_bits) & ((1 << address_bits) - 1)`.
5. `pub fn write_word_port(&mut self, data: u16, now: Tick)` : DI = bit 12, CLK = bit 13, CS = bit 14, appliqués dans cet ordre (cps2.cpp l.1458-1461).

## Règles de portage C++ -> Rust (cartes « port »)
- Traduire fonction par fonction, DANS L'ORDRE du fichier source, mêmes noms en snake_case (`cps1_build_palette` -> `cps1_build_palette` ou nom indiqué). Ne pas « optimiser », ne pas fusionner, ne pas réordonner.
- Types : `int` -> i32, `uint8_t/uint16_t/uint32_t` -> u8/u16/u32 ; arithmétique non signée modulo 2^N : `wrapping_*` ou masques explicites ; division entière C++ = division Rust sur i32 (troncature vers 0).
- Conserver l'en-tête de licence (`// license:BSD-3-Clause` + `// copyright-holders:` du fichier source) en tête de chaque fichier Rust porté, avec le nom du fichier source et les lignes portées.
- Construction sans équivalent évident : écrire la plus simple équivalente et noter `// PORT-NOTE:` ; ne jamais changer le comportement.
