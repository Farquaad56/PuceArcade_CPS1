## Spécification (décidée, ne pas réinterpréter)
Copier `ref/puce16-neogeo/ng-ym2610/fm_engine.rs` et l'adapter à `OpmRegisters` : 8 canaux, 32 opérateurs, `operator_map` des registres OPM, `CSM_TRIGGER_MASK = 0xFF`, `REG_MODE = 0x14`, prescale par défaut 2. Timers (l.1470-1496) : période timer A = `(1024 - timer_a_value) * OPERATORS * prescale` horloges ; timer B = `16 * (256 - timer_b_value) * OPERATORS * prescale`. Statut, IRQ (`update_irq`). Le busy n'est PAS dans le moteur : il est posé par `ym2151::write_data` (T306). `sample_rate(clock) = clock / (prescale * 32)`.
