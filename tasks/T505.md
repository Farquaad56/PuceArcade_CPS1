Tests de bout en bout via `Box<dyn JammaBoard>` uniquement (comme le frontal) :
1. Synthétique : programme 68000 qui recopie en boucle le mot 0x800000 dans 0xFF0000 (`33F9 0080 0000 00FF 0000` MOVE.W $800000,$FF0000 ; `60F4` BRA.S vers 0x400) : `set_inputs` J1 droite + B1, `run_frame` -> mot RAM 0xFF0000 == 0xFFEE (lu via `debug().peek(0, ..)`).

3. Savestate par le contrat (save, 20 trames, load, 20 trames : même crc des pixels).
4. #[ignore] ghouls : 600 trames par le contrat et 600 trames par `Machine` directement -> même crc32 (l'adaptateur ne change rien) ; idem sf2.
