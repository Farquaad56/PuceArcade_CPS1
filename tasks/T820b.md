## Spécification (décidée, ne pas réinterpréter)
Au début de `write16` : si `cps2` est Some, `self.cps2_write16(a, uds, lds, data)` puis retourner `None` (pas de latch son sur CPS2 : le son passe par la RAM partagée, servie par l'hôte).
`cps2_write16` (tableau de la spec, COMBINE_DATA : uds = octet fort, lds = octet faible) : output 400000-40000B (et FFFFF0-FFFFFB si `dead`, la RAM FF0000-FFFFEF et FFFFFC-FFFFFF restant de la RAM), extra RAM, ram664, objram1 700000-701FFF, objram2 708000-70FFFF, CPS-A 800100-80013F et 804100-80413F (`cps_a_write`), CPS-B 800140-80017F et 804140-80417F, banque des objets 8040E0 (`cps2_objram_bank_write(data, lds)`), GFXRAM 900000-92FFFF, RAM FF0000-FFFFFF ; tout le reste ignoré (ROM, 8040A0, 804000-804031, 804040 qui est servi par l'hôte).

## Tests à écrire (valeurs exactes)
- Écriture 400008 = 0x0050 puis lecture 400008 -> 0x50 ; écriture octet fort seul (uds) 400008 = 0x1200 -> 0x1250.
- `dead` : écriture FFFFF8 = 0x40 -> `video.cps2.output[4] == 0x40` et la RAM `ram[0xFFF8 ..]` n'est pas modifiée ; sans `dead`, FFFFF8 écrit la RAM.
- Banque : écriture 8040E0 = 1 (lds) puis écriture 708000 = 0x1111 -> `objram1[0] == 0x1111`.
- Écriture 700002 = 0x2222 (banque 0) -> `objram1[1] == 0x2222`.
- Écriture 804100 + 2 × n (CPS-A) et 800100 (miroir) atteignent `cps_a_write` ; `write16` rend None pour toute adresse CPS2.
