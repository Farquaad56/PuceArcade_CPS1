## Spécification (décidée, ne pas réinterpréter)
```rust
// error.rs
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum CartError {
    Io(String), Config(String), MissingFile { file: String },
    BadSize { file: String, expected: usize, got: usize }, BadCrc { file: String, expected: u32, got: u32 },
    UnknownGame(String), UnsupportedMachine(String), OutOfRegion { region: String, offset: usize },
}
impl std::fmt::Display for CartError  // messages en français, contenant le nom du fichier / jeu ; impl std::error::Error
// config.rs
#[derive(Debug, Clone, PartialEq)]
pub struct Config { pub roms_dir: std::path::PathBuf, pub saves_dir: std::path::PathBuf, pub mame: Option<std::path::PathBuf>,
                    pub game: String, pub allow_bad_crc: bool, pub dips: std::collections::BTreeMap<String, cps_common::Dips> }
impl Config {
    pub const DEFAULT_PATH: &'static str = "cps1.toml";
    pub fn parse(text: &str) -> Result<Config, CartError>;   // CartError::Config(msg) si invalide
    pub fn load(path: &std::path::Path) -> Result<Config, CartError>;  // CartError::Io si illisible
}
```
Format : celui de `cps1.example.toml`. `[paths]` obligatoire avec `roms_dir` ; `saves_dir` défaut `"saves"` ; `mame` optionnel. `[system]` optionnel : `game` défaut `"ghouls"`, `allow_bad_crc` défaut `false`. `[dips]` optionnel : table `nom_du_jeu = { dswa = <entier>, dswb = <entier>, dswc = <entier> }` (les trois clés obligatoires, valeurs 0..=255 sinon erreur). Utiliser la crate `toml` (déjà en dépendance, feature parse) avec `toml::Table` (pas de serde derive).
