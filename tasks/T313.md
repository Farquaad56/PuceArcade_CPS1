## Spécification (décidée, ne pas réinterpréter)
```rust
pub struct Chips { pub ym: ClockedYm2151, pub oki: Okim6295, pub oki_next: Tick, pub oki_current: i32, pub out: Vec<f32> }
impl Chips { pub fn new(oki_rom: Vec<u8>) -> Self; pub fn take_samples(&mut self) -> Vec<f32>; }
impl SoundChips for Chips { ... }
```
- `new` : `oki_next = OKI_DIVISOR_PIN7_HIGH * TICKS_PER_OKI` (665 280), `oki_current = 0`. `reset` : ym.reset(), oki.reset(), oki_next = 665 280, oki_current = 0, out vidé.
- `ym_read/ym_write(offset)` -> `ym.read/write(offset & 1, ..)` ; `oki_read` -> `oki.read()` ; `oki_write` -> `oki.write` ; `set_oki_pin7` -> `oki.set_pin7` (la période change pour les échantillons suivants ; `oki_next` inchangé) ; `irq` -> `ym.irq()`.
- `advance(t)` (t en ticks, multiple de 1408 depuis SoundBoard) : boucle { ty = ym.next_sample_clock() * TICKS_PER_YM ; to = oki_next ; si min(ty, to) > t : fin ; si to <= ty { oki_current = oki.generate() ; oki_next += oki.divisor() * TICKS_PER_OKI } sinon { ym.advance_to(ty / TICKS_PER_YM) ; pour chaque échantillon [l, r] pris : `out.push((l + r) as f32 / 32768.0 * 0.35 + oki_current as f32 / 65536.0 * 0.30)` } } ; puis `ym.advance_to(t / TICKS_PER_YM)` (timers seulement).
