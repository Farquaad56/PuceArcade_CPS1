## Spécification (décidée, ne pas réinterpréter)
Table de touches configurable (sauvée dans `saves/input.toml`) produisant `InputState` (actifs bas) : J1 flèches, A/S/D (B1-B3), Z/X/C (B4-B6 -> IN2), 5 pièce 1, 1 start 1 ; J2 manette ; F2 = test (IN0 bit6), 9 = service.
