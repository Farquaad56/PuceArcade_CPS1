## Spécification (décidée, ne pas réinterpréter)
`impl Video { pub fn cps2_render_sprites(&self, gfx: &[u8], bitmap: &mut [u16], pri: &mut [u8], primasks: &[u32; 8], flip: bool) }` : port 1:1 de l.896-1038 sur `self.cps2` (`buffered_obj`, `last_sprite`, `output`) ; ne rien faire si `cps2` vaut None.
- DRAWSPRITE (l.898-914) -> fonction `draw_sprite2(gfx, bitmap, pri, code, color, flipx, flipy, sx, sy, pmask, flip)` qui appelle `crate::sprites::prio_transpen16` : écran retourné -> `!flipx, !flipy`, position `(512 - 16 - sx, 256 - 16 - sy)`.
- Code direct, **sans** `gfxrom_bank_mapper` (différence avec le CPS1) ; couleur `col & 0x1F` ; pmask = `primasks[priority]`.
- xoffs = 64 − output[4], yoffs = 16 − output[5] (en i32) ; positions `& 0x3FF` ; les 4 cas de blocs dans l'ordre du source (cas sans flip : `(code & !0xF) + ((code + nxs) & 0xF) + 0x10 * nys`).

## Tests à écrire (valeurs exactes)
Convention des tuiles de test (comme sprites_render.rs) : tuile n = octets `n * 128 .. n * 128 + 128` ; 0x00 = pen 0 opaque, 0xFF = pen 15 transparent ; bitmap 512 × 262 rempli de 0xBFF ; `primasks = [0; 8]` sauf mention ; output[4] = 0x40, output[5] = 0x10 (xoffs = yoffs = 0) sauf mention ; `last_sprite = 0`.
- Sprite (x 100, y 50, code 1, colour 3), tuile 1 opaque : bitmap[50 * 512 + 100] == 0x30, bitmap[50 * 512 + 116] == 0xBFF, pri au pixel dessiné == 0x1F.
- Priorité : même sprite avec x = 100 | (2 << 13), `primasks[2] = 0x02`, pri pré-rempli à 1 : rien n'est dessiné.
- colour 0x83, output[4] = 0x50 : pixel dessiné en (x 164, y 66) [x = 100 + 0x50, xoffs = −16 ; y = 50 + 0x10].
- Bloc 2 × 1 sans flip (colour 0x0103, code 0x0F), tuiles 0x0F et 0x10 opaques, tuile 0 transparente : x 100..116 dessiné, x 116..132 non dessiné (la 2e tuile est 0x00, pas 0x10).
- Écran retourné (flip = true), sprite simple en (100, 50) : pixel dessiné en (396, 190).
- y = 50 | 0x2000 : code = 1 + 0x10000 (gfx de 0x10002 tuiles, tuile 0x10001 opaque, tuile 1 transparente) : pixel dessiné en (100, 50).
