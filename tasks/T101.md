## Spécification (décidée, ne pas réinterpréter)
1. Lancer `python tools/extract_dips.py` -> `dips_data.rs` (`#[rustfmt::skip] pub mod dips_data;`) : `DIPS: &[(&str, u8, u8, u8)]` = (bloc INPUT_PORTS, dswa, dswb, dswc).
2. `regions.rs` :
```rust
#[derive(Clone, Debug, Default)]
pub struct Regions { pub maincpu: Vec<u8>, pub gfx: Vec<u8>, pub audiocpu: Vec<u8>, pub oki: Vec<u8>, pub stars: Option<Vec<u8>> }
pub fn build_regions(def: &RomSetDef, src: &dyn FileSource, allow_bad_crc: bool) -> Result<Regions, CartError>;
```
Pour chaque région dans l'ordre : `vec![fill; size]`, puis les ops dans l'ordre avec un état « fichier courant » (données, position de lecture, type) :
- `Load` : `data = src.fetch(file, crc)` ; si `crc32_bytes(&data) != crc` : `BadCrc` (sauf allow_bad_crc : continuer). Si `data.len() < size` : `BadSize{expected: size, got: len}`. Écrire `size` octets depuis la position 0 selon le type (table de docs/spec/04) ; position = size.
- `Continue{offset,size}` : mêmes règles que Load avec le type courant, lecture à partir de la position courante (position += size). `Reload` : position remise à 0 puis comme Continue. `Ignore{size}` : position += size.
- `Copy` : depuis une région déjà construite (`maincpu`/`gfx`/...) ; `Fill` : remplissage ; `NoDump` : ignoré.
- Toute écriture hors de la région -> `OutOfRegion { region, offset }`. Pour Word16Swap et Word64, `size` est pair.
Région inconnue du jeu (ex. « stars » absente) -> `stars: None` ; une région absente du romset reste un `Vec` vide.
3. `game.rs` :
```rust
#[derive(Clone, Debug)]
pub struct Game { pub info: &'static GameInfo, pub regions: Regions, pub ticks_per_68k: u64, pub dips: cps_common::Dips }
pub fn ticks_per_68k(machine: &str) -> Result<u64, CartError>;   // "cps1_10MHz" -> 504 ; "cps1_12MHz" -> 420 ; sinon UnsupportedMachine
pub fn default_dips(input: &str) -> cps_common::Dips;            // ligne de DIPS dont le nom == input ; absente -> Dips::default()
pub fn load_game(cfg: &Config, name: &str) -> Result<Game, CartError>;
// UnknownGame si find_game échoue ; dips = cfg.dips[name] si présent, sinon default_dips(info.input)
pub fn load_game_from(info: &'static GameInfo, src: &dyn FileSource, allow_bad_crc: bool, dips: Option<Dips>) -> Result<Game, CartError>;
```
