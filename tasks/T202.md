`cps1_build_palette` = port 1:1 de l.2612-2646 : `src` part de `base_word` ; pour page 0..5 : si `ctrl` bit page : 0x200 mots copiés (`color_from_word`) vers `palette[0x200*page + i]` ; sinon, si `src != base_word`, `src += 0x200`. PORT-NOTE : l'index de lecture est pris modulo `gfxram.len()`. Les entrées des pages non copiées gardent leur valeur.

## Tests à écrire (valeurs exactes)
- color_from_word : 0xFFFF -> 0xFFFFFF ; 0x0FFF -> 0x555555 ; 0xF800 -> 0x880000 ; 0x1F00 -> 0x600000 ; 0x0000 -> 0 ; 0xF0F0 -> 0x00FF00.
- gfxram de 0x1000 mots où gfxram[i] = 0xF000 | (i >> 9) (page source = i/0x200) ; ctrl = 0b000101 depuis base 0 : palette[0] == color_from_word(0xF000), palette[0x400] == color_from_word(0xF002) (page 1 sautée APRÈS copie de la page 0), palette[0x200] inchangée.
- ctrl = 0b000100 : palette[0x400] == color_from_word(0xF000) (aucune page copiée avant : pas de saut).
- base_word = 0xF00 dans un gfxram de 0x1000 mots, ctrl = 1 : les 0x100 derniers mots puis rebouclage au début (modulo).
