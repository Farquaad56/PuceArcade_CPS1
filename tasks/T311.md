## Tests à écrire (valeurs exactes)
- ROM de 0x40000 octets : entrée d'échantillon 1 à 0x08 : start = 0x000400 (octets 00 04 00), stop = 0x000480 ; write(0x81), write(0x10) -> read() == 0xF1 ; voices[0].count == 2 * (0x480 - 0x400 + 1) = 258 ; après 258 generate -> read() == 0xF0.
- Volume : write(0x81), write(0x18) -> voices[0].volume == 0x02.
- Départ ignoré sur voix occupée et pour start >= stop ; write(0x08) arrête la voix 0 (bits 3-6) ; set_pin7(false) -> divisor() == 165.
