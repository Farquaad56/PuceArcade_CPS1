## Spécification (décidée, ne pas réinterpréter)
```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Layout { L8x8, L8x8b, L16x16, L32x32 }
impl Layout { pub fn size(self) -> u32 /* 8, 8, 16, 32 */; pub fn bytes_per_tile(self) -> usize /* 64, 64, 128, 512 */; }
pub fn tile_pixel(gfx: &[u8], layout: Layout, code: u32, x: u32, y: u32) -> u8;   // pen brut 0..15
```
Algorithme (spec 02) : `elements = gfx.len() / bytes_per_tile` ; si 0 -> 15 ; `code %= elements` ; base de ligne : L8x8/L8x8b `code*64 + y*8`, L16x16 `code*128 + y*8`, L32x32 `code*512 + y*16` ; groupe de 4 octets : L8x8 0, L8x8b 4, L16x16 `(x/8)*4`, L32x32 `(x/8)*4` ; `s = 7 - (x & 7)` ; `pen = ((b[g+3]>>s)&1)<<3 | ((b[g+2]>>s)&1)<<2 | ((b[g+1]>>s)&1)<<1 | ((b[g]>>s)&1)` (b[g+3] = plan d'offset 24 = bit 3).

## Tests à écrire (valeurs exactes)
- gfx = vec![0; 1024] ; L16x16 code 1 (base 128) : gfx[131] = 0x80 -> pixel(0,0) == 8 ; gfx[128] = 0x01 -> pixel(7,0) == 1 ; gfx[134] = 0x80 -> pixel(8,0) == 4 ; gfx[128+8*15+7] = 0x01 -> pixel(15,15) == 8.
- L8x8 code 0 : gfx[2] = 0x40 -> pixel(1,0) == 4 (octet +2 = plan d'offset 16 = bit 2) ; L8x8b code 0 : gfx[6] = 0x40 -> pixel(1,0) == 4 ; gfx[5] = 0x01 -> L8x8b pixel(7,0) == 2 (octet g+1 avec g = 4) ; L8x8 pixel(7,0) reste 0.
- L32x32 code 0 : gfx[12+1] = 0x01 -> pixel(31,0) == 2 ; gfx[16*2 + 0] = 0x80 -> pixel(0,2) == 1.
- Modulo : avec gfx de 1024 octets (8 tuiles 16x16), code 9 donne les mêmes pixels que code 1 ; gfx vide -> 15.
