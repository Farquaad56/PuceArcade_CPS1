## Spécification (décidée, ne pas réinterpréter)
Dans `video_io.rs` (`impl Video` séparé), port 1:1 :
```rust
pub fn cps_a_write(&mut self, word: usize, data: u16, uds: bool, lds: bool);   // l.2115-2134 : COMBINE_DATA ; si word == 5 : copie de palette
pub fn cps_b_read(&self, word: usize) -> u16;                                  // l.2136-2181 (ordre de spec 02 §CPS-B ; raster non porté : P7)
pub fn cps_b_write(&mut self, word: usize, data: u16, uds: bool, lds: bool);   // l.2183-2244 : COMBINE_DATA (raster/out2 non portés)
pub fn vblank(&mut self);   // screen_vblank_cps1 puis cps1_objram_latch : get_video_base(), puis buffered_obj[i] = gfxram[(bases.obj + i) % GFXRAM_WORDS], i < 0x400
```
Comparaisons de cps_b_read/write : `word as i32 == cfg.cpsb.cpsb_addr / 2` (division i32, -1/2 == 0). `cpsb_value` renvoyé tronqué `as u16`. Produit : `(regs_b[(f1/2) as usize] as u32) * (regs_b[(f2/2) as usize] as u32)`. Index négatif impossible (les -1 deviennent 0). Copie de palette : `cps1_build_palette(&mut palette, &gfxram, cps1_base(5, 0x400), regs_b[(palette_control/2) as usize])`.

## Règles de portage C++ -> Rust (cartes « port »)
- Traduire fonction par fonction, DANS L'ORDRE du fichier source, mêmes noms en snake_case (`cps1_build_palette` -> `cps1_build_palette` ou nom indiqué). Ne pas « optimiser », ne pas fusionner, ne pas réordonner.
- Types : `int` -> i32, `uint8_t/uint16_t/uint32_t` -> u8/u16/u32 ; arithmétique non signée modulo 2^N : `wrapping_*` ou masques explicites ; division entière C++ = division Rust sur i32 (troncature vers 0).
- Conserver l'en-tête de licence (`// license:BSD-3-Clause` + `// copyright-holders:` du fichier source) en tête de chaque fichier Rust porté, avec le nom du fichier source et les lignes portées.
- Construction sans équivalent évident : écrire la plus simple équivalente et noter `// PORT-NOTE:` ; ne jamais changer le comportement.
