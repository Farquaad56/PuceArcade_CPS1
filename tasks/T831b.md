## Spécification (décidée, ne pas réinterpréter)
Dans `cps2_read` / `cps2_write` :
- Lecture 804020 : `(inputs.in2 & 0xFFFE) | eeprom.do_read(now) as u16` (bit 0 actif haut).
- Écriture 804040 : si uds -> `eeprom.write_word_port(data, now)` ; si lds -> `sound.set_z80_reset(data & 0x0008 == 0, z80)` ; adresse servie (true). Le Z80 est rattrapé jusqu'à `now` **avant** le changement de ligne de reset (`z80_run_until(now)`, comme pour les latches).

- EEPROM 16 bits pilotée par des écritures 804040 (uds) qui reproduisent la séquence d'écriture du test de T803 (adresse 5, 0x1234), puis lecture : les bits lus en 804020 bit 0 donnent 0x1234.
