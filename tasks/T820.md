## Spécification (décidée, ne pas réinterpréter)
1. `cps2_io.rs` : `#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub struct Cps2Inputs { pub in0: u16, pub in1: u16, pub in2: u16 }` (Default : 0xFFFF partout) ; `pub struct Cps2Io { pub inputs: Cps2Inputs, pub extra_ram: Vec<u8> /* 0x4000 */, pub ram664: u16, pub dead: bool, pub singbrd: bool }` (Clone, Debug, serde) avec `new(dead, singbrd)`.
2. `VideoPort` gagne, avec implémentation par défaut (lecture 0, écriture sans effet) : `cps2_output_read(&self, word) -> u16`, `cps2_output_write(&mut self, word, data, uds, lds)`, `cps2_objram1_write(&mut self, word, data, uds, lds)`, `cps2_objram2_read(&self, word) -> u16`, `cps2_objram2_write(&mut self, word, data, uds, lds)`, `cps2_objram_bank_write(&mut self, data, lds)`. `video_port.rs` les implémente pour `cps_gfx::Video` en déléguant à `self.cps2` (None : comme le défaut).
3. `Bus68k` gagne `pub cps2: Option<Box<Cps2Io>>` (None dans `new_cps_bus`). Au début de `read16` : si `cps2` est Some, retourner `self.cps2_read16(a)` (méthode dans cps2_io.rs, `impl<V: VideoPort> Bus68k<V>`), tableau de la spec : ROM `read_rom_word`, output (400000-40000B ; et FFFFF0-FFFFFB si `dead`), extra RAM 660000-663FFF, ram664, 700000-701FFF -> 0, objram2 708000-70FFFF (`(a - 0x708000) / 2 % 0x1000`), CPS-B 800140-80017F et 804140-80417F, IN0 804000, IN1 804010, IN2 804020, volume 804030 (0xE021, ou 0xD000 si `singbrd`), DSW 8040B0-8040B3 -> 0xFFFF, GFXRAM 900000-92FFFF, RAM FF0000-FFFFFF (`self.ram`), sinon 0. Les adresses 618000-619FFF ne sont jamais vues ici (servies par l'hôte).
