## Spécification (décidée, ne pas réinterpréter)
Reprendre le motif « split » de Neo Geo : `Machine::split(&mut self) -> (&mut Cpu, Host68k<'_>)`, `Host68k` emprunte tous les autres champs.
`impl puce_m68k::bus::Bus for Host68k` :
- `read(addr, _fc, uds, lds)` -> `bus.read16(addr, uds, lds)` ; `write(...)` -> `bus.write16(...)` puis `Some(Latch1(v))` -> `sound.set_latch(0, v)`, `Latch2` -> `set_latch(1, v)`.
- `wait_clocks` -> 0 (Q-WAIT). `ipl()` -> `match (ipl1, ipl2) { (false,false) => 0, (true,false) => 2, (false,true) => 4, (true,true) => 6 }`. `int_ack(_level)` -> ipl1 = ipl2 = false ; `None` (autovecteur).
- `on_tick(_pins)` : `*now += ticks_68k` ; puis `while sound.time + TICKS_PER_Z80 <= *now { sound.tick(z80) }` ; puis `if *now >= *next_vblank { vblank_event() }` (en T401 : `vblank_event` = `*next_vblank += TICKS_PER_FRAME; *frame += 1; *frame_done = true` ; T402 y ajoute IRQ et rendu).
`sched.rs` : `pub fn run_frame(&mut self)` : `frame_done = false` ; boucle `cpu.step_clock(&mut host)` jusqu'à `frame_done` ; puis `finish_instruction()` (step_clock jusqu'à `cpu.at_instruction_boundary()`). `pub fn finish_instruction(&mut self)`. Pas d'autre source de temps.

## Tests à écrire (valeurs exactes)
- Programme : vecteurs SSP 0x00FF8000 PC 0x400 ; à 0x400 `60FE` (BRA.S *). Après run_frame() : `frame_count() == 1`, `now >= 77_414_400` et `now < 77_414_400 + 30 * 504` ; `sound.time <= now && sound.time + 1408 > now`.
- Deuxième run_frame() : `now >= 77_414_400 + 84_510_720`.
- Latch : programme `13FC 00AB 0080 0181` (MOVE.B #$AB,$800181) puis BRA.S * : après run_frame, `sound.latch[0] == 0xAB`.
- Déterminisme : deux machines identiques, 3 trames : même `now`, même `cpu.state()`, même `z80.regs.pc`.
