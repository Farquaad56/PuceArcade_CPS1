## Spécification (décidée, ne pas réinterpréter)
Reprendre la structure de `ref/puce16-neogeo/ng-bus/sound.rs` (serveur de broches qui appelle `cpu.tick(pins)` une fois par T-state) avec la carte du CPS1.
```rust
pub trait SoundChips {
    fn ym_read(&mut self, offset: u8) -> u8;       // offset 0/1
    fn ym_write(&mut self, offset: u8, data: u8);
    fn oki_read(&mut self) -> u8;
    fn oki_write(&mut self, data: u8);
    fn set_oki_pin7(&mut self, high: bool);
    fn irq(&self) -> bool;                         // sortie IRQ du YM2151
    fn advance(&mut self, t: Tick);                // amène les puces à l'instant t (ticks)
    fn reset(&mut self);
}
// chips_stub.rs : NullChips (ym_read -> 0x00, oki_read -> 0xF0, irq -> champ pub `irq: bool`, enregistre les écritures dans `pub log: Vec<(u16, u8)>` avec 0xF000/0xF001/0xF002/0xF006 comme clé)
pub struct SoundBoard<C: SoundChips> { pub rom: Vec<u8>, pub ram: Vec<u8>, pub bank: u8, pub latch: [u8; 2], pub chips: C, pub time: Tick, /* état du port (broches) comme Neo Geo */ }
impl<C: SoundChips> SoundBoard<C> {
    pub fn new(rom: Vec<u8>, chips: C) -> Self;   // rom = région audiocpu (0x18000), ram = vec![0; 0x800]
    pub fn reset(&mut self);                       // bank 0, latches 0, ram 0, chips.reset(), set_oki_pin7(true), état du port remis à zéro ; time conservé
    pub fn set_latch(&mut self, n: usize, v: u8);  // n = 0 (latch1) ou 1 (latch2)
    pub fn read(&mut self, addr: u16) -> u8; pub fn write(&mut self, addr: u16, v: u8);
    pub fn input(&mut self, port: u16) -> u8 /* 0x00 */; pub fn output(&mut self, port: u16, v: u8) /* ignoré */;
    pub fn irq_level(&self) -> bool;               // chips.irq()
    pub fn tick(&mut self, cpu: &mut puce_z80::Cpu);
}
```
Carte (docs/spec/01 §Z80) : 0000-7FFF `rom[a]` ; 8000-BFFF `rom[0x10000 + bank*0x4000 + (a-0x8000)]` (0 si hors tampon) ; D000-D7FF RAM ; F000/F001 `chips.ym_read/ym_write(a & 1)` ; F002 OKI ; F004 W `bank = v & 1` ; F006 W `chips.set_oki_pin7(v & 1 == 1)` ; F008 R latch[0] ; F00A R latch[1] ; reste : lecture 0x00, écriture ignorée.
`tick` : identique au modèle Neo Geo (données lues/écrites selon les broches du tick précédent, octet 0xFF au cycle d'acquittement), puis **`self.chips.advance(self.time)`** avant d'échantillonner INT (`Pins::INT` si `irq_level()`), jamais de NMI, `cpu.tick(pins)`, puis `self.time += TICKS_PER_Z80` (1408).

## Tests à écrire (valeurs exactes)
- read : rom[0x0123] ; bank 0 -> read(0x8010) == rom[0x10010] ; write(0xF004, 1) -> read(0x8010) == rom[0x14010] ; write(0xD7FF, 9) -> read(0xD7FF) == 9 ; read(0xC000) == 0 ; set_latch(1, 0x33) -> read(0xF00A) == 0x33.
- Programme `3A 08 F0 32 00 D0 76` (LD A,(F008) ; LD (D000),A ; HALT), latch1 = 0x5A, 40 appels de tick : ram[0] == 0x5A et `time == 40 * 1408`.
- Programme `3E 2B 32 01 F0 76` (LD A,0x2B ; LD (F001),A) : NullChips.log contient (0xF001, 0x2B) ; `3E 00 32 06 F0 76` : log contient (0xF006, 0) et l'appel set_oki_pin7(false).
- Interruption : programme `ED 56 FB 76` (IM 1 ; EI ; HALT) et à 0x0038 `3E 77 32 00 D0 76` ; NullChips.irq = true ; 200 ticks -> ram[0] == 0x77.
