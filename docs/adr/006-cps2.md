# ADR 006 — CPS2 dans le même projet
- Contexte : le CPS2 de MAME 0.287 (`cps2_state : cps_state`) réutilise la base CPS1 déjà portée (CPS-A/CPS-B, tilemaps, palette,
  QSound, EEPROM, raster) et ne redéfinit que le chiffrement du 68000, la carte mémoire, la RAM objets, les sprites, la composition
  des couches et les entrées. Spec : `docs/spec/05-cps2.md`.
- Décision : pas de nouveau crate ; chaque crate gagne une variante CPS2 activée par un champ optionnel, comme QSound (ADR-005).
  1. **cps-cart** : `romsets2_data.rs` généré (`GAMES2`), `find_game` cherche dans `GAMES` puis `GAMES2`, `romset::system_of`,
     `support_of` CPS2 (machines `cps2`/`dead_cps2`, inits `init_cps2`/`init_singbrd`). `cps2crypt.rs` (port 1:1 de
     `cps2crypt.cpp`, tables générées `cps2crypt_tables.rs`) et décodage du `.key`. Chargement : région `key`, `unshuffle` des
     graphismes, opcodes déchiffrés dans `Game::cps2 : Option<Cps2Rom>`, horloge 25 200/59 (ADR-007).
  2. **cps-gfx** : `Video::cps2 : Option<Box<Cps2Video>>` (RAM objets, banque, registres output, tampon latché, priorités) ;
     `cps2_sprites.rs` (cps2_render_sprites), `cps2_render.rs` (render_layers CPS2 et tilemaps avec valeur de priorité).
     `Video::raster : Option<Raster>` branché sur CPS-B (ADR-003 a) ; `Video::hpos` fourni par l'hôte avant chaque accès CPS-B.
  3. **cps-bus** : EEPROM 93C46 paramétrée (8 ou 16 bits) ; `Bus68k::cps2 : Option<Box<Cps2Io>>` (cps2_map / dead_cps2_map hors
     hôte) ; `VideoPort` gagne les accès CPS2 (méthodes par défaut) ; `SoundBoard` sait tenir le Z80 en reset.
  4. **cps-core** : horloge fractionnaire du 68000 ; `Machine::new` construit la variante CPS2 ; l'hôte sert les opcodes déchiffrés
     (FC programme), la RAM QSound en 618000, IN2 (DO EEPROM) et le port 804040 (EEPROM, reset Z80), et ordonnance le raster par
     ligne (ADR-003 b). Savestate version 4.
  5. **cps-gui** : entrées CPS2 (dispositions 4 joueurs, 6 boutons, qndream) ; le pilote expose les jeux CPS1 puis CPS2 dans un
     même catalogue (« Capcom CPS1 / CPS2 ») ; même `Cps1Board`, son stéréo QSound, EEPROM dans `<saves>/<jeu>.nv`.
  6. Ordre de validation : `ssf2ud` (Phoenix, aucun mot déchiffré : démarre sans le chiffrement), puis jeux chiffrés (`ddtod`,
     `sfa3`, `xmvsf`) contre les golden MAME, puis `xmcota` (effets raster, rendu partiel ADR-003 c).
- Conséquences : `cps-common` reste gelé (ports CPS2 sur 16 bits définis dans `cps-bus`, `Cps2Inputs`) ; aucune branche CPS2 dans
  les chemins CPS1 hors des champs optionnels : golden CPS1 inchangés. Hors champ : cps2comm (ssf2tb), gigaman2, pzloop2, ecofghtr.
- Cartes impactées : T800 à T851.
